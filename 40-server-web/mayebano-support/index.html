分流与 DNS 联动，Mesh 组网更新

2026-09-11
5 → 3 · DNS域名分流与加密解析

添加域名分流时，可同时设置加密 DNS，并在重载后清理路由器 DNS 缓存。

5 → 3 · 订阅同步订阅下载策略

可为匹配域名的 HTTP 订阅设置下载出口，修复分流后订阅仍走直连的问题。

5 → 3 · 重载分流重载修复

已有规则可继续重载，重载后检查分流、订阅与 DNS 设置。

Mesh 1.20.1-2级联组网与断线恢复

完善 Q6000 级联组网、节点拓扑，以及无线重载、换信道后的重连。

ghproxy.vip下载加速

脚本、插件和配置包下载统一使用 ghproxy.vip。

C2000UltraSD 卡与 Swap 适配

HC-WT9500 接入 SD 卡检测与 Swap 管理；新建默认 512 MiB，可扩容至 2048 MiB，应用商店同步显示实际总量与使用量。

AdGuardHome安装后同步 DNS 设置

与哈基米联用时，统一路由器本机和局域网普通查询的 AdGuardHome DNS 链，保留域名专用上游；按实际配置变化重启对应服务。

下载体验进度与断点续传

下载进度取自实际传输，结合断点续传与备用地址回退；终端菜单和提示同步适配手机操作，减少重复等待。

MT5700 WebUI5800 双线路页面

C5800-650 / C5800-688 检测到双线路时并列展示信号，详情可切换线路，AT 连接与计划独立管理；插件安装登记仅更新自身条目。

应用商店 V3卡片与弹窗优化

应用卡片等高排列、操作按钮对齐，手机按钮更易点击；弹窗随可用高度伸展，精简顶部空白，统一插件名称和状态展示。

LuCI / 温度系统总览与温度切换

完善 8080 原生 LuCI 登录与系统总览，隔离主题设置；支持机型的 CPU / 5G 温度切换即时刷新，并记住所选温源。

5G 连接监听记录与任务状态完善

补齐事件写入失败后的记录和自动、手动任务结果，增加频段停留筛选；支持 C5800-650 / C5800-688 / C2000MAX，智能频段仅向 C5800-688 开放。

安装步骤

01

激活后台 SSH

C8-788 安装 SSH 管理 IPK；AK68-798 恢复 SSH 配置包；其他支持机型通过后台隐藏页面开启 SSH。

NRadio_C8-788

  1. 下载下方 C8-788 SSH 管理 IPK（插件版本 1.0.1-1）。
  2. 进入 NRadio 应用商店，选择本地安装并上传该 IPK。
  3. 安装完成后确认应用商店出现“SSH 管理”卡片，状态显示“已安装”。
  4. 点击“打开”，进入插件页面启用 SSH 并保存。
下载 C8-788 SSH 管理 IPK

NRadio_AK68-798 · TCP 2222

适用识别码：HC-WT9194 / HCMT7987-S256。

  1. 进入“更多”，点击“备份/升级”。
  2. 下载 AK68-798-SSH-2222.nr。
  3. 在“恢复配置”处选择下载的 .nr 文件，点击“上传”。
  4. 恢复完成后重启路由器，使用 LAN 地址连接，端口 2222。
下载 AK68-798 SSH 配置包

SSH 登录使用设备现有密码。

其他支持机型 · SSH 隐藏页面

  1. 先正常登录 NRadio 后台。
  2. 点击下方按钮，或把隐藏页面地址粘贴到当前浏览器地址栏打开。
  3. “开启SSH”选择“启用”，点击“保存&应用”，等待设置完成后再连接 SSH。
